# X 热门视频榜（本地版）

在你自己电脑上运行的一个小工具：用你浏览器里已登录的 X 账号，抓取公开视频数据，
按**播放量**或**点赞数**排出榜单，点一下就能跳回原推，也可以直接下载视频。

不需要服务器，不需要把账号交给任何人，所有数据只存在本机。

---

## 功能

- **两种榜**：播放量榜 / 点赞榜，一键切换
- **七种时间维度**：24 小时 / 3 天 / 一周 / 一个月 / 一年 / 往年（按年翻页）/ 殿堂
- **殿堂**：每天只收「当天发布的视频里播放量最高的那一条」，一天一张卡，从今天一直往回翻到 2022 年 12 月
- **按自然月翻页**：一个月榜右侧有 ◀ ▶，能一个月一个月往前翻
- **H 模式**：只显示 X 标记为敏感的媒体，开启前需先在 X 设置里打开两个开关（页面内有浮窗说明）
- **加载更多**：每次 36 条，一直能往下翻
- **下载**：单条视频下载到 `Videos\x-rank`，完成后可一键打开所在文件夹
- **自动更新**：程序会自己检查 GitHub Release，有新版本给一条提示，点一下就下载到桌面

## 使用

1. 双击 `X热门视频榜.exe`
2. 浏览器会自动打开 `http://127.0.0.1:2717`
3. 第一次用要填两个值（页面顶部有折叠说明）：
   - 打开 x.com 并确认已登录 → `F12` → Console → `copy(document.cookie)` → 粘到第一个框
   - `F12` → Application → Cookies → `https://x.com` → 找 `auth_token` → 复制 Value → 粘到第二个框
4. 点「保存并验证」

凭证只保存在本机，不会上传到任何服务器。

**关闭**：右键任务栏右下角的托盘图标 → 退出；或页面底部「退出程序」。

## 注意

- 需要能正常访问 x.com
- 搜索接口有频率限制，翻得太快会提示「被限流了，等 15 分钟再试」，等一会儿即可
- 榜单是**基于搜索结果的样本**，不是 X 全站普查；账号关注越多、越活跃，能看到的样本越宽
- 新注册、几乎没关注任何人的账号，X 会降低搜索权重，看到的内容会明显偏少
